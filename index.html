🌐 Laboratorio remoto (origin)

Simula el ciclo completo: rama → edición → commit → push → merge → push. Nada se envía a GitHub real.

Flujo guiado de colaboración

git switch -c feature/Mariana → touch ejemplo.txt → git add . → git commit -m "Nueva funcionalidad" → git push -u origin feature/Mariana → git switch main → git merge feature/Mariana → git push origin main

Usa git remote -v y git branch -a para explorar el remoto.

🧠 Git avanzado · Laboratorio seguro

Practica cambios temporales, restauración de commits, cherry-pick y versiones. Estas operaciones son simuladas y no alteran GitHub real.

git stash push

Guarda cambios pendientes temporalmente.

git stash list / pop

Consulta y recupera los cambios guardados.

git cherry-pick HASH

Replica un commit de otra rama; rechaza conflictos para evitar pérdidas.

git reset --soft HASH

Mueve HEAD conservando los cambios preparados.

git reset --hard HASH

Descarta cambios y restaura la instantánea seleccionada.

git tag v1.0.0

Crea una etiqueta que apunta al commit actual.

🧪 Comandos disponibles

git push origin main

Publica commits en el origin simulado.

git pull origin main

Integra los cambios del remoto virtual.

git fetch origin

Actualiza referencias remotas, sin modificar archivos.

git remote -v

Consulta el remoto configurado.

git diff

Compara el área de trabajo con el último commit.

git rm / git mv / git restore

Elimina, renombra o restaura archivos.

git status

Consulta la rama actual, el staging y los cambios pendientes.

git add .

Prepara los cambios para el siguiente commit.

git commit -m "mensaje"

Guarda una instantánea de los archivos.

git switch -c feature

Crea una nueva rama y cambia a ella.

git switch main

Regresa a una rama existente.

git merge feature

Fusiona historias y detecta cambios incompatibles.

git log

Inspecciona la historia de commits.

git branch

Consulta las ramas y cuál está activa.

touch archivo.txt

Crea un archivo vacío en tu área de trabajo.
